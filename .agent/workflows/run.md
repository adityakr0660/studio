// turbo-all

1. Start the backend server:
```
npm run dev
```
Run this in the `d:\Studio\photo-studio-mern` directory. This starts the Express backend on port 5000.

2. Start the frontend dev server:
```
npm run dev:frontend
```
Run this in the `d:\Studio\photo-studio-mern` directory. This starts the Vite React frontend on port 5173.

3. The app is now available at http://localhost:5173/
